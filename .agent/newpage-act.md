# 사도행전 구조도 시연 웹 어플리케이션 개발 요구사항 정의서

본 프로젝트는 사도행전 구조도 시연 스크립트의 흐름에 맞춰, 청중의 시선을 제어하고 말씀의 서사를 시각적으로 극대화하기 위한 인터랙션 웹 페이지 개발을 목표로 합니다.

---

## 🏛️ 1. 전체 화면 구조 (메인 레이아웃)
- **최초 진입 화면:** 중앙에 2개의 메인 카드 박스가 배치된 심플한 레이아웃 구성
  - **Left Box:** [개요] 버튼 (팝업 트리거)
  - **Right Box:** [구분] 버튼 (팝업 트리거)
- **전체 무드:** 과한 오버레이나 화려한 연출을 지양하고, 여백과 타이포그래피 중심의 담백하고 세련된 미니멀 UI 지향

---

## 🖼️ 2. 상세 인터랙션 및 컴포넌트 요구사항

### 📍 파트 1: [개요] 세션 팝업
- **동작:** [개요] 박스 클릭 시 중앙 레이어 팝업 활성화
- **화면 구성:** 상단 `주제` 영역 / 하단 `핵심구절` 영역 분할
- **핵심 인터랙션 (블라인드 효과):**
  - 최초 진입 시 주제와 핵심구절의 텍스트 콘텐츠는 어두운 블라인드(Blur 또는 반투명 레이어)로 가려져 있어야 함.
  - **1차 클릭:** 주제 영역의 블라인드가 투명해지며(`opacity: 0`, `transition` 적용) 내부 텍스트 노출
    - *주제 텍스트:* `주제 : 하나님의 사람들이 펼쳐가는 성령행전`
  - **2차 클릭:** 핵심구절 영역의 블라인드가 걷히며 사도행전 1장 8절 말씀이 크게 노출
    - *핵심구절 텍스트:* `오직 성령이 너희에게 임하시면 너희가 권능을 받고, 예루살렘과 온 유대와 사마리아와 땅끝까지 이르러 내 증인이 되리라 하시니라 (사1:8)`

---

### 📍 파트 2: [구분] 세션 팝업 (가로 확장 아코디언)
- **동작:** [구분] 박스 클릭 시 구조도 탐색 팝업 활성화
- **상단 영역 (3분할 가로 아코디언 구조):**
  - 초기 상태: 3개의 박스(`1번: 1-7장`, `2번: 8-12장`, `3번: 13-28장`)가 동일한 Flex 비율(`flex: 1`)로 정렬됨.
  - **클릭 이벤트 핸들링:** 
    - 특정 박스 클릭 시, 해당 박스는 `width: 70%` (`flex: 7`)로 부드럽게 확장됨.
    - 나머지 비활성화된 2개의 박스는 상대적으로 축소 처리됨.
    - 확장된 박스 내부에는 각 단락의 **대주제**와 **대상(인물/장소)**이 강조되어 노출됨.

- **하단 영역 (장별 상세 내용 렌더링):**
  - 상단 아코디언 박스 클릭 시, 하단 영역의 데이터 리스트가 해당 단락의 장별 소주제 및 내용 카드로 Dynamic 업데이트(Refresh)되어야 함.

## 💻 4. 개발 참고 및 퍼포먼스 가이드 (FE)
- **Transition 속성:** 아코디언 확장 시 `transition: flex 0.5s ease-in-out` 또는 `width` 변화가 부드럽게 튀지 않도록 리듬감을 부여해 주세요.
- **가독성:** 장별 내용 리스트가 노출될 때 텍스트 양이 많으므로 적절한 폰트 높이(`line-height: 1.6`)와 카드 간 여백(Padding)을 충분히 확보해 가독성을 높여주시기 바랍니다.
